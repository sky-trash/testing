Тест 1: Создание поста

Название теста: Проверка функциональности создания нового поста

Цель тестирования: Убедиться, что пользователь может создать новый пост и все его свойства корректно сохраняются.

Предпосылки:

Список постов пуст

Шаги тестирования:

1. Создать пост с заголовком "Мой первый пост", содержанием "Это содержание моего первого поста" и автором "Иван Петров"
   Ожидаемый результат: Пост успешно создается, возвращается объект поста

2. Проверить ID созданного поста
   Ожидаемый результат: ID = 1

3. Проверить заголовок поста
   Ожидаемый результат: Заголовок = "Мой первый пост"

4. Проверить содержание поста
   Ожидаемый результат: Содержание = "Это содержание моего первого поста"

5. Проверить автора поста
   Ожидаемый результат: Автор = "Иван Петров"

6. Проверить количество комментариев
   Ожидаемый результат: 0 комментариев

7. Проверить наличие дат создания и обновления
   Ожидаемый результат: Даты определены
