Тест 1: Добавление транзакции дохода

Название теста: Проверка добавления транзакции с типом "доход"

Цель тестирования: Убедиться, что пользователь может добавить доход и он корректно учитывается в балансе.

Предпосылки:
Приложение запущено
Существует категория "Зарплата"

Шаги тестирования:

1. Добавить транзакцию дохода на сумму 50000 рублей в категории "Зарплата" с описанием "Зарплата за январь"
   Ожидаемый результат: Транзакция успешно создается, возвращается объект транзакции

2. Проверить ID транзакции
   Ожидаемый результат: ID = 1

3. Проверить сумму транзакции
   Ожидаемый результат: Сумма = 50000

4. Проверить тип транзакции
   Ожидаемый результат: Тип = income

5. Проверить категорию
   Ожидаемый результат: ID категории = ID категории "Зарплата"

6. Проверить описание
   Ожидаемый результат: Описание = "Зарплата за январь"

7. Проверить общее количество транзакций
   Ожидаемый результат: 1 транзакция

8. Проверить общий доход
   Ожидаемый результат: Общий доход = 50000

9. Проверить общий расход
   Ожидаемый результат: Общий расход = 0

10. Проверить баланс
    Ожидаемый результат: Баланс = 50000
