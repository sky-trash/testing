Сценарии тестирования TodoList Application

Тест 1: Создание задачи

Название теста: Проверка функциональности создания новой задачи

Цель тестирования: Убедиться, что пользователь может создать новую задачу и все ее свойства корректно сохраняются в системе.

Предпосылки:
Приложение запущено
Список задач пуст

Шаги тестирования:

1. Создать новую задачу с названием "Купить продукты" и описанием "Молоко, хлеб, яйца"
   Ожидаемый результат: Задача успешно создается и возвращается объект задачи с заполненными полями

2. Проверить общее количество задач в списке
   Ожидаемый результат: Количество задач равно 1

3. Проверить ID созданной задачи
   Ожидаемый результат: ID равен 1 (автоматически присвоен системой)

4. Проверить название задачи
   Ожидаемый результат: Название задачи = "Купить продукты"

5. Проверить описание задачи
   Ожидаемый результат: Описание задачи = "Молоко, хлеб, яйца"

6. Проверить статус выполнения задачи
   Ожидаемый результат: Статус completed = false (задача не выполнена)

7. Получить список всех задач и проверить наличие созданной задачи
   Ожидаемый результат: Созданная задача присутствует в общем списке


Тест 2: Редактирование задачи

Название теста: Проверка функциональности редактирования существующей задачи

Цель тестирования: Убедиться, что пользователь может изменить название и описание уже созданной задачи.

Предпосылки:
Приложение запущено
Создана задача с названием "Старая задача" и описанием "Старое описание"

Шаги тестирования:

1. Отредактировать существующую задачу: изменить название на "Новая задача" и описание на "Новое описание"
   Ожидаемый результат: Метод редактирования возвращает true (успех)

2. Получить обновленную задачу по ID
   Ожидаемый результат: Задача найдена и возвращена

3. Проверить новое название задачи
   Ожидаемый результат: Название задачи изменилось на "Новая задача"

4. Проверить новое описание задачи
   Ожидаемый результат: Описание задачи изменилось на "Новое описание"


Тест 3: Удаление задачи

Название теста: Проверка функциональности удаления задачи

Цель тестирования: Убедиться, что пользователь может удалить задачу и она полностью исчезает из системы.

Предпосылки:
Приложение запущено
Созданы три задачи: "Задача 1", "Задача 2", "Задача 3"

Шаги тестирования:

1. Проверить начальное количество задач
   Ожидаемый результат: Количество задач = 3

2. Удалить задачу с ID = 3 ("Задача 3")
   Ожидаемый результат: Метод удаления возвращает true

3. Проверить обновленное количество задач
   Ожидаемый результат: Количество задач = 2

4. Попытаться найти удаленную задачу по ID
   Ожидаемый результат: Задача не найдена (возвращается undefined)


Тест 4: Отметка задачи как выполненной

Название теста: Проверка функциональности отметки задачи выполненной

Цель тестирования: Убедиться, что пользователь может отметить задачу как выполненную и это влияет на фильтрацию задач.

Предпосылки:
Приложение запущено
Создана задача "Сделать домашнее задание" со статусом "не выполнено"

Шаги тестирования:

1. Отметить задачу как выполненную
   Ожидаемый результат: Метод отметки возвращает true

2. Проверить статус задачи
   Ожидаемый результат: Статус completed изменился на true

3. Получить список выполненных задач
   Ожидаемый результат: В списке выполненных задач присутствует отмеченная задача

4. Получить список активных (невыполненных) задач
   Ожидаемый результат: В списке активных задач отсутствует отмеченная задача


Тест 5: Получение отфильтрованных списков задач

Название теста: Проверка функциональности фильтрации задач по статусу выполнения

Цель тестирования: Убедиться, что система корректно разделяет задачи на выполненные и активные.

Предпосылки:
Приложение запущено
Созданы три задачи: "Задача 1", "Задача 2", "Задача 3"
Задача 2 отмечена как выполненная

Шаги тестирования:

1. Получить список всех задач
   Ожидаемый результат: Общее количество задач = 3

2. Получить список выполненных задач
   Ожидаемый результат: Количество выполненных задач = 1, и это задача с ID = 2

3. Получить список активных (невыполненных) задач
   Ожидаемый результат: Количество активных задач = 2, это задачи с ID = 1 и ID = 3


Тест 6: Негативные сценарии

Название теста: Проверка обработки ошибок при работе с несуществующими задачами

Цель тестирования: Убедиться, что система корректно обрабатывает попытки работать с несуществующими задачами и не изменяет существующие данные.

Предпосылки:
Приложение запущено
Создана одна реальная задача с названием "Реальная задача"

Шаги тестирования:

1. Попытаться отредактировать несуществующую задачу (ID = 999)
   Ожидаемый результат: Метод редактирования возвращает false

2. Попытаться удалить несуществующую задачу (ID = 999)
   Ожидаемый результат: Метод удаления возвращает false

3. Попытаться отметить несуществующую задачу как выполненную (ID = 999)
   Ожидаемый результат: Метод отметки возвращает false

4. Попытаться найти несуществующую задачу по ID (999)
   Ожидаемый результат: Метод поиска возвращает undefined

5. Проверить общее количество задач
   Ожидаемый результат: Количество задач осталось = 1 (реальная задача не пострадала)

6. Проверить, что реальная задача не изменилась
   Ожидаемый результат: Название реальной задачи по-прежнему = "Реальная задача"


Тест 7: Автоматическое присвоение ID

Название теста: Проверка автоматической генерации идентификаторов задач

Цель тестирования: Убедиться, что система автоматически присваивает уникальные возрастающие ID каждой новой задаче.

Предпосылки:
Приложение запущено
Список задач пуст

Шаги тестирования:

1. Создать первую задачу "Задача 1"
   Ожидаемый результат: ID созданной задачи = 1

2. Создать вторую задачу "Задача 2"
   Ожидаемый результат: ID созданной задачи = 2

3. Создать третью задачу "Задача 3"
   Ожидаемый результат: ID созданной задачи = 3

4. Проверить общее количество созданных задач
   Ожидаемый результат: Количество задач = 3
