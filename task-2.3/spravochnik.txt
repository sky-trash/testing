   Ожидаемый результат: ID = 1

   Ожидаемый результат: Название = "Война и мир"

4. Проверить автора книги
   Ожидаемый результат: Автор = "Лев Толстой"

5. Проверить ISBN книги
   Ожидаемый результат: ISBN = "978-5-17-123456-7"

6. Проверить год издания
   Ожидаемый результат: Год = 1869

7. Проверить доступность книги
   Ожидаемый результат: isAvailable = true (книга доступна)

8. Проверить общее количество книг
   Ожидаемый результат: 1 книга
